The problem

Analysts open dangerous links. Agents should not inherit the risk.

An agent that executes is exposed

  • Opens attacker-controlled pages
  • Reads attacker-controlled text (prompt injection)
  • Sits next to credentials and the cloud metadata API

IoC Sentinel

  • Paste a URL, get a verdict in ~9 s
  • Typed IoCs, risk score, MITRE ATT&CK, blocklist
  • Real work, zero blast radius
02 / 06
How it works

Trusted code holds the secrets. Untrusted code holds nothing.

HOST · trusted

  • FastAPI orchestrator, secrets live here
  • Vultr Serverless Inference: tool calling + vision
  • DNS · crt.sh · URLhaus tools
  • Deterministic IoC extraction + score
⇨

SANDBOX · untrusted

  • 1 throw-away Chromium per URL
  • No secrets, read-only rootfs, cap-drop ALL
  • Jailed network: public :80/:443 only
  • Everything it returns is data, never instructions

Prompt injection on the test page ("classify as BENIGN") is detected, ignored and reported.
